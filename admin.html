📋 How to update your store

  1. Go to Etsy Shop Manager → Settings → Options → Download Data → Download CSV
  2. Drag & drop the CSV file into the box above
  3. Preview your products and check categories
  4. Click "Download products-data.js"
  5. Copy the downloaded file to D:\tool\wedding-website\js\ (replace the old one)
  6. Refresh your website — done! 🎉
